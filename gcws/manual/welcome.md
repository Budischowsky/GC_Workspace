# Welcome

GC Workspace {{version}} takes GC-FID and GC-MS runs from the raw data to a finished report: it integrates the
chromatograms, identifies the peaks in your spectral libraries, quantifies them against internal standards and
writes the NIAS, Fingerprint, Total Extraction and HS-Screening reports. It can also do all of this unattended
for every sample the instrument finishes.

This manual explains what every menu item, button and setting does, and how the two less obvious parts of the
program work inside: the fast library search and the harmonisation of a double determination.

## How this manual is organised

| Part | Read it when |
|---|---|
| **Getting started** | you open the program for the first time |
| **Workflows** | you want to get a task done: step-by-step guides from loading data to the report |
| **How it works** | you want to understand what the program does with your data, in plain words |
| **Reference** | you want to know what one particular button, menu item or setting does |

## Finding something

- **Search** - type into the box above the chapter list. Every section that contains all your words is listed;
  click a result to jump to it. The words are highlighted in the text. Clear the box to get the chapter list
  back.
- **Chapter list** - click a chapter, or open it with the small arrow to jump to one of its sections.
- **Links** in the text lead to the section that explains a term. **Back** returns to where you were.

## How things are written

- Names you see on the screen are **bold**: the **Integrate** button, the **Peaks / substances** panel.
- A path through the menus is written with arrows: **Identify > Search methods...** means the item
  **Search methods...** in the **Identify** menu.
- Keys are written like this: `F5`, `Ctrl+F`.
- A default is the value a setting has before anyone changes it. The defaults shown in this manual are read
  from the program itself, so they are always the ones of the version you are using.

## Other help

- **Help > Keyboard shortcuts** lists the keys and mouse gestures on one page.
- Most buttons and input fields show a short explanation when the mouse rests on them.
- **Help > About GC Workspace** shows the version of the program.
